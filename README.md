# Laravel + React Starter Kit + Inertia

## 𝐇𝐑 Projet

### 👥 Plateforme de gestion des ressources humaines. 
- Annuaire des employés avec photos et profils,
- gestion des services et des postes,
- processus de demande et de validation des congés
- système de pointage (arrivée/départ), de feuilles de temps, de fiches de paie mensuelles imprimables (PDF)
- un tableau de bord avec des graphiques en temps réel et de rapports CSV pour les audits.

### 💻 Technologie
- 🐘 Laravel 13
- ⚛️ React 19
- </> Inertia.js
- #️⃣ Tailwind CSS
